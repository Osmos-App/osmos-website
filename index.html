§1 — The Experience

Focus on the work, not the files.

01

Every version is already there.

Every moment is remembered automatically. Revert a single file or your entire workspace instantly. If you make a mistake, simply step back in time.

02

Sync without the cloud.

Work entirely offline. Osmos discovers your devices on the local network and syncs the moment you connect. No external servers involved.

03

Private by design.

Your files belong to you. Everything is end-to-end encrypted before it moves. Total ownership, built in.

§2 — Architecture

The technology matters. You shouldn't have to think about it.

§3 — Specification

Built for permanence.

Core Engine
Rust · with optional gitoxide backend
Interface
Tauri, React, TS
Architecture
Decentralized · local-first, peer-to-peer
Versioning
Snapshots · two-level rollback
Conflict resolution
Timestamp (LWW) · admin queue for pending changes
Discovery
mDNS (_osmos._tcp.local)
Encryption
AES-GCM via CryptoKit · Noise Protocol for transport
Recovery
BIP-39 · 24-word recovery phrase
Platform
Windows, macOS, Linux
Status
v0.1.0-α · In active development
